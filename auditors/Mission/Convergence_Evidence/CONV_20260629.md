## Comparative Analysis

### What External Identity Changed

1. **Floors raised across all metrics.** Hardcoded Claude avg: 0.7–3.6 per metric. External Claude avg: 3.1–4.4. Grok moved from 0.2–2.0 to 1.8–4.0. The LITE files give Grok's empirical lens enough nuance to credit observable evidence (IP's historical record, LS's logical structure) rather than demanding falsifiability on every metric.

2. **CA found genuine common ground.** Multiple external runs converged Round 1 at 4.0–5.5. Both lenses credit CT's causal framework (first cause, necessary being) partially. This is substantive agreement, not capitulation.

3. **Crux distribution shifted.** Hardcoded: MS dominant (3/7 runs). External: IP dominant (4/10 runs). Identity source changes which philosophical tensions surface — a methodological finding, not noise.

4. **Deliberation became genuine.** External runs show auditors moving toward each other across rounds through actual reasoning, not one-sided capitulation.

### What Did NOT Change

- IP remained the most volatile metric in both conditions
- Claude oscillation pattern persisted (amplified under external identity)
- The general ordering of metric stability was consistent

## Key Methodological Findings

**1. Identity condition must always be reported.** Results without identity condition tag are ambiguous. `external_identity: true` is the recommended condition for all future CFA runs.

**2. IP requires a locked definition.** The score range (0.1–10.0 across runs) is not measurement noise — it maps a definition-space manifold. Claude reads "historical lineage"; Grok reads "empirical traction." These are different questions about the same metric. Locked definitions (Iteration 3) needed before IP scores are interpretable.

**3. The variance itself is a finding.** CT's profile under adversarial pressure is characterized by its instability as much as any central tendency. A worldview that scores 1.0–7.5 on Explanatory Scope depending on how auditors define "explanation" has a genuinely contested explanatory claim.

**4. MdN-as-subject run needed.** This batch evaluated CT through MdN's lens. MdN was never scored as subject. A symmetric run (Claude PRO-MdN, Grok ANTI-MdN) is required to complete the profile pair.
