CFA CREATIVE COLLABORATORS — WORKING MAP
Updated October 8, 2026

One project brief and reference map travel between tools. Each tool gets instructions for its particular job. An image uploaded to one service is not presumed available in another.

GROK
Design exploration: character styling, wardrobe, tattoo artwork, scene ideas and storyboard drafts. Return exact download names and reference roles. A liked tattoo, outfit or location does not approve every detail in its image.

GEMINI
Creative conversation and generation: interpret the song, refine shot ideas, create references and video candidates using the tools actually available. Existing Gemini project instructions remain the character/story brief. Record the effective model and actual attachments for each result.

GOOGLE FLOW
Dedicated image/video production workspace: prepare reference ingredients or starting frames, generate individual shots and explore continuity between related takes. Use flow_brief.txt plus the relevant project's flow/project_brief.txt and flow_shot_template.txt. It is a Google product. Nano Banana is an image model family; Flow's available video models include Veo and Gemini Omni. Product, model and project are different fields in our records.

CFA / COMFY
Keep the source library, roles, accepted decisions and measured experiment records. Prepare bounded edits, soundtrack replacement, optional lip-sync and final finishing as separate jobs. Match a recipe to what changes and what must remain. Cloud availability, execution and user acceptance are separate evidence states.

PANHANDLER NOVA
Maintain the reusable teaching material in Pan_Handlers/Help through our manual handoff. CFA holds the production evidence. Each repository can run without the other checkout at runtime.
