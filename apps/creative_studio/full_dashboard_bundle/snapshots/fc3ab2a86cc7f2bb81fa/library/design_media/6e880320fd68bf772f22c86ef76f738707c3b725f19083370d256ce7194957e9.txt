For Seedance 2.5, this node's aspect ratio follows the first image; there is no
separate ratio widget. The common 16:9 source supplies the target aspect.
Documented choices are 480p/720p/1080p, 4–30 seconds, and an audio toggle.
The last frame is optional. A numeric seed does not make this service
deterministic, and equal seed numbers across different models are not equal noise.
Image validation and oversized-image downscaling exist upstream; inspect any
actual preprocessing and output rather than assuming exact pixel preservation.

The official file named api_seedance2_5_i2v_1080p.json instead uses a general
reference-image node. The first/last-frame recipe selected here has an explicit
first_frame input, which better matches our common starting-frame comparison.
