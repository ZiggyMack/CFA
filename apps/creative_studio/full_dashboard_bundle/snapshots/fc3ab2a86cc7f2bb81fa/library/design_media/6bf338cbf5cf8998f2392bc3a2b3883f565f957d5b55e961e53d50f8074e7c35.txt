# GROK-HD-TATTOO-GUIDE-v001 — Hon Dolo tattoo placement guide (FIRST PROOF)

Built with PIL only. No image generation, and no art was redrawn. **Nothing in this package is new original art.** Every motif image is an unmodified pixel crop of a source file. The only drawing is annotation (circles, numbers, labels, white fills). Source SHA-256 hashes are in MANIFEST.csv.

## Files
- `HD-TATTOO-PLACEMENT-GUIDE_v001.png`: neutral (desaturated, low-contrast) LOCK-FACE head with numbered callouts, a legend (motif / location / CHARACTER-side + viewer side / source + sha256-12 / status), a viewer-orientation banner, the forearm inset (#6 Scoundrel) and an UNPLACED box.
- `clean_art/`: CA01–CA16 unmodified crops of the source motifs, kept separate from the guide.
- `flat_1_STENCIL-ONLY.png`: copy of flat_1.jpg with the character-imagery tiles 36, 41, 42, 43, 45, 46 (the wolf), 48 and 49 white-filled. Captions are kept. The original is untouched.
- `flat_0_LABELED.png` + `flat_0_INDEX.csv`: index badges and short motif labels, with each label linked to its sheet caption and, where one was found on the box, the original filename.
- `MANIFEST.csv`: file, sources, sha256, transformation, remaining defects.
