REVIEW ROUTE
1. Choose Prime or MM_1 and listen against its own audio.
2. Start with flags, then repeated phrases and vocal/event hotspots. Preview uses
   the reported range, selected lead-in and a 0.35-second tail. Seek sets the exact
   reported start without playing. Continue listening removes the preview stop.
   Starting one track pauses the other.
3. Compare report 02 anchors against report 03 full lines. Prime report 04 remains
   a separate follow-up; earlier and revised events are not silently merged.
   MM_1 follow-up 04 is a bounded extract of 56 lines up to source line 80.
   The completed report 03 remains its primary full-line map.
4. Check repeated whisper occurrences, CJ!, DOCTOR?, long compound source lines,
   overlaps and transitions against the actual audio.
5. Add a note identifying the cut, source line/event, what you heard, proposed
   onset/ending or occurrence distinction. Export JSON for separate review.
   The page never auto-accepts or grades timing or writes into project records.
