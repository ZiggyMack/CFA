CHAT
Configure Chat offers Default, Learning Guide or Custom role/style, with Default/Longer/Shorter responses. Select relevant Sources before asking. For CFA, a useful Custom direction is: "Be our creative development and continuity collaborator. Keep the current story and reference roles clear. Propose bold ideas as proposals. Cite evidence for existing decisions and say which source is missing when you cannot answer. Prefer one useful next step to an exhaustive questionnaire."

AUDIO OVERVIEW
Deep Dive: develop an idea in conversation. Brief: quick single-speaker summary, documented as under two minutes. Critique: constructive feedback. Debate: opposing views for a real unresolved choice. Language and a steering prompt are available; English also has Shorter/Default/Longer duration controls. Exact runtime is not an editing timeline.
CFA defaults: Brief for status; Critique for story readability; Deep Dive for exploring theme. Debate is optional when two creative treatments actually compete, not for reopening settled character details.
https://support.google.com/gemininotebook/answer/16212820?hl=en

VIDEO OVERVIEW
Current help lists Cinematic, Explainer and Short (about sixty seconds). Narration language and topic/steering prompt are available. Cinematic currently supports English. Explainer can use a visual-style preset, Auto-select or Custom; the style chooser excludes Cinematic and Short. Presets include Classic, Whiteboard, Watercolor, Retro Print, Heritage, Paper-craft, Kawaii and Anime. Some controls have age restrictions.
Use Explainer + a restrained custom look for a project orientation; Short for a quick introduction. Cinematic is an optional presentation experiment if offered. We do not infer exact character preservation, production-shot controls or song lip-sync from any of these formats. Old Nyquist cards saying video "Brief" are historical; the prepared Lisan card uses the current "Short" name.
https://support.google.com/gemininotebook/answer/16454555?hl=en

SLIDE DECK
Detailed Deck supports standalone reading; Presenter Slides supports a presenter. Choose language, Short/Default/Long length and a prompt describing audience, outline and style. Customize before generation with the pencil control. Desired slide counts in our prompts are editorial requests, not guaranteed exact output.
Use Detailed Deck + Short for our working lookbooks. Google's help states that sources are not considered during slide revisions: recheck revised labels, character details and asset IDs against the originals.
https://support.google.com/gemininotebook/answer/16757456?hl=en

INFOGRAPHIC
Choose language; Concise/Standard/Detailed (beta); Square/Portrait/Landscape; style or automatic selection; and a custom description. Professional, Sketch Note and Kawaii are documented style examples. Use Landscape + Standard for relationships; Portrait for a compact character checklist. A style choice affects presentation, not reference approval.
https://support.google.com/gemininotebook/answer/16758265?hl=en

REPORTS
Current dedicated help distinguishes Interactive and Document. Templates can be customized through Edit; generation can run now or later. Use Document with an available briefing/custom template for CFA handoffs. Field names vary; the help does not enumerate every setting. Paste the full report card into the available instruction/customization field. If that UI is unavailable, obtain the same text through chat and save the response with its citations; record that it was a chat response, not a Studio report.
Interactive reports with embedded artifacts are optional for later teaching material. A direct next-shot brief rarely needs all those outputs.
https://support.google.com/gemininotebook/answer/18323649?hl=en

SOURCE AND QUALITY CHECK
Each card chooses a purpose and a small source set. Use generated diagrams for relationships, not as proof of character appearance. Compare visual output with the actual referenced assets. A source citation supports a fact, not the fidelity of a generated face or stencil. Neither exporting an artifact nor saving a chat automatically promotes it to a source in another notebook.
The master connects projects through explicit evidence-bearing handoffs; Google documents that a notebook cannot itself be another notebook's source.
https://support.google.com/gemini/answer/16972047?hl=en
