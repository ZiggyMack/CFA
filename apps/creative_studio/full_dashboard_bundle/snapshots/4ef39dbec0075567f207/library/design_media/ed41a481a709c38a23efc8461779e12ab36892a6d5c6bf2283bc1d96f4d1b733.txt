HOW TO READ THE BADGES
Character and Scene are independent from their existing stars, favorite, triage,
creative lane, manual stage and human acceptance. Legacy Verification remains
a manual stage; it is never converted to an AI pass.
Not checked / Pass / Fail / Uncertain are assessment results. Required / Optional /
N/A is separate applicability. N/A is not pass. Pass is always for the named scope.
A missing original, missing nominated reference, required occluded detail, unknown
criteria, changed hash/version/scope or stale tolerance cannot yield a current pass.
Required jewelry cannot be waived as asymmetry. Use the documented variant and
placement tolerances; optional accessories remain separate. A detail crop cannot
validate a whole actor, a scene or motion.

COMPARE ACTUAL IMAGES
Choose an existing scoped nomination and criteria. Inspect the original target
and original reference. Record each required criterion: visible/occluded/missing/
unknown, pass/fail/uncertain/not checked, and concrete observations. A filename,
provider "good", file decode, star score or contact-sheet thumbnail is not a pass.
Record target and reference exact IDs, SHA256 and immutable sha256: version;
criteria ID/version/digest; named scope; actually seen image IDs/hashes/version;
reviewer, actual model (or human), surface, time; evidence, uncertainty and provenance.
Do not claim to have viewed a reference because it was listed in a packet.
Current beta includes only seven originals actually viewed by Site Index.
Nova PA's 21 full-size observations remain separately attributed and are not
converted to formal passes. DeepSeek deepseek-v4-pro's reported setup explicitly
does not declare image input; no DeepSeek visual grades were imported. Its B1/B2
text work is separate, and no model switch or calibration is activated.

PERSISTENCE AND HISTORY
Evidence has an independent cfa-reference-validation-v1 browser key and append-only
assessment IDs. Re-importing the same ID/content is harmless; conflicting content
is rejected atomically. New assessments retain older history. The current badge
summarizes the latest result in each scope; an unrelated N/A cannot hide a pass,
and a narrow pass cannot hide unresolved work in another scope.
Readiness requires the latest current pass for each exact declared scope.
Export validation evidence creates a standalone portable file. Full Save review
file / Export review includes validationEvidence and legacyReviewArchive.
Old imports do not clear evidence. Raw canonical/browser/import review records
are archived losslessly outside normalizedReview, whose existing operational
field handling remains unchanged. Existing review/favorites/basket keys remain.
Unknown or corrupt evidence in either browser store is retained in unreadBackups
with its source key and exact original text. Exports include that archive alongside
all valid evidence and raw legacy records. A current unread store blocks evidence
imports before mutation; export the backups before resolving that original store. Storage failure means
current page state is not durable: export before closing.
A downloaded/exported record is not host intake or notification. One site owner
publishes vetted source metadata via build_catalog.py. No watcher is installed.

READINESS AND REFERENCE MAP
The old human scene gate remains separate. Technical readiness additionally needs
a versioned per-scene/use declaration with exact required target/axis/criteria/scope
checks, and every check must currently pass. No declared set means unresolved,
not an empty-set success. No scene-use declarations were invented by this beta.
The 18 existing BOM entries retain acceptance evidence. Eight explicit nominations
have criteria transcribed from current scoped policies; ten default choices,
family IDs and derivative gaps remain open. No new gold/reference actor/pet chosen.
Hon cockpit consistency is required only where explicitly locked; existing
scene-specific Falcon use does not establish a universal set. Lisan environments
remain open unless explicitly locked. Located dog candidates are not nominated.
Source updates must bump criteria versions and recompute the criteria digest.
The builder checks pinned policy and reference bytes before publication. Prior
evidence is retained and displays stale if its target/reference/criteria changes.

MOUTH COVERAGE
Recipe input readiness and optional artwork coverage are different. The verified
Cantina v004 graph uses WanAnimateToVideo / Wan2.2 Animate Mix: one actor still,
CLIP Vision, aligned face/pose/background sequences and mask. It requires zero
still-atlas slots. Audio enters CreateVideo; the final composite protects/restores
the source mouth. It does not prove newly generated speech or rap lip-sync.
The reported face-only DWPose versus RGB-face-crop representation concern remains
unresolved until actual runtime frames/contract are inspected. No graph changed.
Hon's dated art plan has 50 macros plus 130 unique head-state/view slots per look.
Optional pitch adds 40 (170 unique heads, not 190). Key-state selection is not
accepted. Lisan's inherited optional art plan has 49 numbers, skipping Hon's
chain-bite #47. No universal viseme count or automatic bank expansion follows.
Keep articulation, expression/action, yaw, pitch, identity/dental revision,
grill/breather/lip rings and props separate. Counts are source hashes and provider
labels, not independently distinct usable poses. Multiple takes do not add slots.
Seven Lisan human Production mouth details cover five labels; all old reviews
remain. The 38 R2 retries and three later optional grill repairs are received,
unchecked candidates. Their malformed CSV note quoting is preserved in originals;
the typed intake verifies the final digest tokens/SHA256SUMS and source bytes.
Static validation does not establish temporal speech. A later bounded clip needs
a chosen audio-driven route or synchronized driving performance, exact track
excerpt/timebase/FPS, visible needed mechanics, sound+picture and frame inspection,
and per-look/phrase evidence. No run, spend, timing acceptance or launch is authorized.
