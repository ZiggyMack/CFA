## How to use this map

- **HaL's shortlist**: lead with the categories marked in bold (C13, C15, C35, C36), then the chorus set (C01, C02, C04, C21, C40), then the rest by section. Name files, not slots. Reconcile the on-disk counts (953, 43 categories) with the "all 45 at 22+" message before the shortlist is called complete.
- **CFA Nova's catalog**: the LAG-1K set has no entries today (one string mention of "LAG-1K" in `visual_library/catalog.js`, inside a Lisan mouth-set note); C13-04 cannot carry a storyboard_prime tag until it has an entry. Section codes above can be the catalog's grouping.
- **Repair briefs**: apply the team's own tips to any shortlisted frame with a lettering or worm defect (eye first; "four letters, the I included"; flat black ink; Dune-style worms, not snakes; framing chosen per shot, since the bots disagree on front-facing versus three-quarter), and keep the head standard. Mirroring a file to move the worm to the other side of frame is not a repair: it mirrors the tattoos and the chin lettering too.
