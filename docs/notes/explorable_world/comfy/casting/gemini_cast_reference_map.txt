HOW TO USE THIS MAP
- Treat the user message picture numbers as illustrative examples, not actual file selections.
- Stable reference IDs are labels in this map; source files have not been renamed.
- A file inventoried in CFA is not proof that it has been attached to Gemini. Verify actual attachments before using it.
- Bind upload batch ID + picture number + exact filename + reference ID explicitly. Never infer a mapping from upload order or a similar filename.
- Do not use bare #3 across batches; use e.g. CAST-BATCH-001/P03 with its exact filename. Leave unbound fields empty until actually supplied.
- Latest direct user corrections override older instructions. Only explicit user selection promotes a candidate to primary/approved.
- Use only each reference's assigned role; do not merge faces, transfer one character's tattoos onto another, or restore retired details.
- Existing video continuity is a separate brief from creating a new likeness. Do not silently replace a liked clip's face.
- Keep rejected/superseded sources as history, excluded from active generation unless requested.
- If a listed picture is missing or ambiguous, say which one; ask only the blocking question and proceed with independent planning.
- Do not include every cast reference in every generation. Supply the characters and details required by that shot.
- For the Han Solo.png group source, use the separate HD-LIKENESS-03, LEIA-LIKENESS-01 or LUKE-LIKENESS-01 crop for the intended character. The group image remains provenance, not a direct multi-face conditioning input. Exact-pixel cropping creates no design approval.
