## Choosing the best references

The initial sort separates current working anchors, candidates, storyboards, inspiration and retired/conflicting exploration. Select the best files by purpose; a wardrobe favorite need not become the face master. Candidate/flagship labels preserve the supplied reference role and existing selections, not new acceptance of every visible detail.

Keep filenames and version folders while reviewing, especially where earlier Lisan scenes reuse `LAG-SC-NN` names. Each project's manifest can recover the original file even if a review copy is later moved. Unclassified or conflicting items remain available rather than being deleted. Supplied helper scripts are inert source material and were not executed.

Shared Comfy recipes remain in `../workflows/` with project-specific prefixes, preserving existing links and Cloud run evidence.
