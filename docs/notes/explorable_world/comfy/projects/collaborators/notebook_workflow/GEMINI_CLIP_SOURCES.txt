GEMINI VIDEO: CLIP-SPECIFIC NOTEBOOK SOURCES
Adopted CFA operating guidance, October 14, 2026, from Ziggy's Bellglass review and immediate source-scope refinement.
This is CFA's project application. Nyquist remains the general notebook-method home; preserve the existing README ownership breadcrumbs.

WORKING RULE
Use notebook sources AND an explicit production prompt. Before generating a short clip, load or activate only the material pertinent to that clip. Do not leave a whole ten-minute scene active merely because the requested clip belongs somewhere within it. Keep the full screenplay/master storyboard separately for planning and provenance.

PREPARE THE CLIP
1. Name the project, shot/clip ID, intended beat, approved scene-card revision and exact coverage within the larger scene or track. Retain the parent document's path/hash and the excerpt's location.
2. Build a small source pack: the relevant scene excerpt; only necessary character/prop/location/continuity references; actor action, expression and eyeline; lighting; camera/framing/movement; background action; start/end state and the cut boundary. Include adjacent-beat context only when this clip needs it, clearly labeled as context rather than another action to perform.
3. Preserve the writer-approved wording and existing scoped decisions. Do not mix Hon and Lisan, unrelated shots, rejected alternatives or later-scene actions into this active pack. Lyrics can guide meaning/cut points without requiring singing or mouthing every word. Performance accents and ordinary spoken dialogue must be explicitly assigned.
4. Check the ACTUAL notebook and selected source bodies/revisions. Record source IDs, filenames/hashes, included excerpts and excluded material. A local pack or upload acknowledgement alone is not proof of active remote context.
5. If the surface supports source selection, use and verify that selection. If it cannot isolate the relevant material, prepare a clean clip-scoped notebook/context through the supported route, retaining the master elsewhere. A new chat inside a loaded notebook does not by itself clear notebook sources, prior chat context or custom instructions. Inspect inherited context through supported UI; do not assume isolation.
6. Record the exact immediate prompt. Repeat critical shot requirements and preservation constraints explicitly even when they are also in the sources. Notebook context supplements the prompt; it is not a guarantee that every loaded fact will appear. The Bellglass test deliberately omitted cues for diagnosis; ordinary production should not do that.

CHECK THE RETURN
Preserve the actual source selection, exact prompt, native tool/mode, visible chat model, job/chat/response IDs, original result and defects. Distinguish the chat-model label from an unexposed video renderer. Inspect visuals, motion and audible sound separately. Use current supported account limits; an unexposed metadata field alone is not an execution gate, while an actual extra-charge/purchase request is a separate decision.

BELLGLASS EVIDENCE AND ACCEPTANCE
One source-only-context video returned one 10-second 1280x720 clip. The immediate prompt omitted dog, blue collar and barking. The loaded copied-text source contained them. A dog with a vivid blue/cyan collar appears in the result. Ziggy reviewed it and confirmed the dog plus a quick head motion as if barking; its mouth did not move, which he regarded as minor. He accepts this as confirmation that notebook context can contribute to video generation and directs us to use it for scene/storyboard details.
This feedback did not separately confirm audible barking; do not turn head motion or an audio stream into a listening claim. The missing mouth articulation remains a recorded defect, not a regeneration order.
Which source details will be chosen remains uncertain. This one end-to-end result does not reveal direct renderer retrieval versus intermediate prompt assembly or guarantee every source will be used. Clip-specific scoping is Ziggy's operational direction; prevention of source bleed has not been separately measured.
