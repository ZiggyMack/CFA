## Choose by problem

Start from the requested change and preservation needs, then read the matching lesson before adapting a graph. This lookup connects the [Panhandlers ledger](../../../../../../Pan_Handlers/Help/CFA_TUTORIAL_LEDGER.md) to the concrete CFA recipes. Entries retain dated evidence; recheck the saved graph and Cloud dependencies when resuming. The current settings are baselines for testing, not measured optima.

| Request or observed problem | Technique and relevant lesson | Recipe and next controlled check |
| --- | --- | --- |
| Keep the video but replace its soundtrack or wrong words | Exact replacement audio, matching trim and source FPS. [Video/audio handoff](../../../../../../Pan_Handlers/Help/guides/video_handoff.py). | [Audio Replace](hon_dolo_audio_replace_v001.README.md): local stream-copy proof completed; native Cloud editor saved/server-converted with live schemas and inputs checked, not executed. Use the separate prepared Sync graph only when visible mouth movement must change. No lip-sync execution yet. |
| Animate an existing still into a new short shot | Starting-frame appearance plus an action/camera prompt. [Video routes](../../../../../../Pan_Handlers/Help/content/video_routes.py), `image_to_video`. | **Hon Dolo Motion Test**, below. Completed 960 × 512 / 24 fps / 97-frame native LTX-2.5 preview. Sampled review shows prolonged eye closure and smile drift; acceptance pending. A still provides no source performance to preserve. |
| Compare a hosted Seedance model using the same starting frame | Reuse the `image_to_video` lesson above and [controlled comparisons](../../../../../../Pan_Handlers/Help/guides/sampling_lab.py); keep the shared frame, action and target duration. | [Seedance 2.5 first-frame candidate](seedance_2_5_20261009.README.txt). Official graph saved/reviewed only; prepare a separate eight-second / 720p copy with the optional last frame disconnected, then verify Cloud schemas, inputs and quote. Deferred from initial benchmark counts; no execution or acceptance. Extension returns only a new segment, requiring explicit assembly with the parent. |

[Video handoff](../../../../../../Pan_Handlers/Help/guides/video_handoff.py) and `FINISHING` in [video routes](../../../../../../Pan_Handlers/Help/content/video_routes.py). | **No accepted CFA video master or verified finishing result yet.** Select a compatible finishing recipe after acceptance, then check texture stability, timing and audio. Resizing pixels alone does not demonstrate restored detail. |
