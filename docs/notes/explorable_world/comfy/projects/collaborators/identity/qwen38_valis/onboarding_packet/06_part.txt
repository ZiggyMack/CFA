**First asset experiment.** The completed image follows [pump_brief.json](pump_brief.json) and [pump_concept_prompt.txt](pump_concept_prompt.txt). Its palette, service panel, and silhouette read clearly, but the housing feels too pristine and slender; visible repairs and the lever socket need further work. Carry that direction into the authored prototype prop, using a repair plate, a replaced coupling, and wear around the service panel. A static generated mesh is a separate experiment. The game supplies its moving lever, water behavior, and interaction logic; a later mesh experiment must also establish a plausible engine import and cleanup path.

Save the chosen workflow JSON under `workflows/` when it has been inspected. Duplicate [templates/run_record.json](templates/run_record.json) to record the template/model version, actual inputs, job identifier, output filenames, and observed usage alongside it. Workflow exports must not contain API keys, authorization headers, or temporary signed download URLs.

Preview remotely where possible. Put necessary downloaded images and meshes under `outputs/` on D:; that directory ignores generated files in Git by default. Preserve bulk originals in a verified cloud archive once connected, and keep only the local references and derivatives needed for the current chapter. Keep original downloads separate from edited game assets, and promote an asset only after checking its scale, silhouette, mesh complexity, materials, and suitability in the test scene. The workflow record should identify its storage location, required cleanup, and the model's applicable usage terms.

The active video pipeline succeeds when a source shot and transformed result can be compared in motion, the intended change works, timing and identity meet the brief, and the accepted output and recipe can be retrieved. The earlier game-asset pipeline additionally required a 3D review and engine test; those are no longer prerequisites for video production.

If the server is configured but absent from a running chat's tool list, report that distinction. A stored connection alone does not establish that the current session can invoke its tools.
