STORYBOARD SOURCE MATURITY - OCTOBER 29, 2026
Coordinator: CFA Nova. Based on Ziggy's proposal to distinguish storyboards
using mature source images from preliminary or unreviewed starting material.
This addendum describes the derived display and sorting rule, not new asset
approval, a generation request, or a change to existing human reviews.

PURPOSE
Make the strength of the selected visual foundation visible at a glance while
preserving the separate maturity of writing, technical checks and actual video.
Apply this alongside PRODUCTION_METHOD_20261012.txt and REFERENCE_POLICY.txt.
The settled-reference/team-progression method remains in force: no repeated
human approval is required merely to reuse an already accepted reference.

AUTOMATIC FOUNDATION INDICATOR
1. Use an explicitly selected starting image for first-frame work. Resolve its
   exact asset ID, bytes/hash and intended role against current scoped evidence.
   Merely linked art, inspiration and a named identity reference are not a
   selected starting frame. Do not pick an image automatically to fill the gap.
2. Show the actual source stage, review scope and provenance. A Detailed design
   source provides a Detailed foundation. Verification or Production sources
   also provide a Detailed foundation, retaining their exact source stage in
   the explanation. These are source-stage labels, not technical pass claims.
3. A Preliminary source provides a Preliminary foundation. An existing source
   without a recorded stage is Maturity not recorded, not silently Preliminary.
   No selected image is No starting frame selected. Explicit work from scratch
   is From scratch; an image-free route is Not required only when documented.
4. A component's maturity follows only its component. A Production mouth,
   tattoo, outfit or identity reference cannot stand in for a complete selected
   scene image. Preserve known differences, defects and scoped exceptions.
5. For ingredients/edit/extend modes, report the maturity of each selected
   required input in its own role (including source video). Do not take the
   highest stage across unrelated references or assume every mode needs a
   starting image. Mixed input maturity stays visibly mixed.
6. Missing assets, hash mismatch or conflicting selection evidence must be
   visible as unresolved or changed input. Changing an input recomputes the
   derived indicator and flags dependent packs/checks for review; it does not
   overwrite old stages, results, reviews or previously accepted decisions.

STORYBOARD AND VIDEO PROGRESSION
The derived indicator does not write storyboardStage, user ratings or result
acceptance. The storyboard may progress to Detailed design when the team has
checked its relevant direction, intended scoped inputs, continuity and remaining
requirements under the existing production method. Do this autonomously where
authorized; do not create another blanket user gate. A mature scene image saves
preparation work but does not establish new camera movement, performance,
music/lyric timing, lip sync, route compatibility or generated-video acceptance.
An exploratory exception can proceed within its stated scope while defects
remain visible. From-scratch writing is not a quality failure.

SITE PRESENTATION
Keep storyboard stage and source foundation separately labelled. Offer a
foundation filter in Structure & gaps, with an explanation showing which exact
selected input caused the label. Preserve missing-field indicators and the
isolated blank template. Do not promote any of the 70 current Hon shots merely
because they link a mature component or old panel. At this handoff no prepared
starting frame is documented for those shots in the current structure records.
Reuse explicit intake/selection evidence; do not infer it from filenames or
create an artificial selection workflow just to populate the indicator.

EXAMPLES
- Production scene frame selected + unfinished camera direction:
  Detailed foundation / source Production; storyboard keeps its current stage;
  camera work remains visible.
- Preliminary scene frame selected: Preliminary foundation; scoped accepted
  character references remain accepted and do not need reapproval.
- Production mouth + identity reference, no prepared scene frame:
  No starting frame selected; both component scopes remain visible.
- A storyboard written without any selected media: No starting frame selected,
  or From scratch only if explicitly documented; keep the written work visible.
- A frame changed since its technical checks: source maturity may be recorded,
  but dependency checks are stale and cannot be presented as a current pass.
