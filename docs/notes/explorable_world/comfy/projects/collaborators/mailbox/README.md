# Shared collaborator mailbox

Read [MAILBOX.md](../MAILBOX.md) for the workflow and [I_AM.md](../I_AM.md) for the welcome and introduction guidance.

- [registry.json](registry.json): recipient IDs and intended routes. A listed route is not proof of delivery or access.
- [messages/](messages/README.md): one immutable file per addressed message.
- [receipts/](receipts/README.md): separate immutable evidence of later actions.
- [Message template](templates/message.json) and [receipt template](templates/receipt.json): fill and save with a fresh UUID filename.

Nothing is automatically sent or monitored. Check during active work sessions and leave a closing handoff.
