WINDOWS BROWSER MEDIA ALIASES

Generated by visual_library/browser_media_paths.py during catalog build.
Some received original paths exceed Windows MAX_PATH and cannot be loaded by
the browser even though extended-path Python intake checks can read them.

These short hash-named files are hard links to the original media on D:, not
lower-resolution previews or a second payload copy. Keep them read-only in
practice: changing an alias changes the same underlying original bytes.
The source paths, filenames, IDs and hashes in the catalog remain unchanged.
visual_library/browser_media_paths.json records each source-to-browser alias.

The links are regenerated when missing. Git ignores the generated aliases so
they are not stored as duplicate media payloads in repository history.
