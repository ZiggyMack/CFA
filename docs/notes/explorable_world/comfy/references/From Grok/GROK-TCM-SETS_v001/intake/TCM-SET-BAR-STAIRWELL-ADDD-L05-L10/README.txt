6. L05, L06, L09 and L10 show a blank door-closer plate above or on the door. Nothing is legible at 1x, but check at 4x.
7. P02 "wedge gap at the bottom": with the wedge on the roof side, the gap reads only as a daylight line under a closed door. This is faint in L06.
8. Filename form follows B3; the light token is the plain word "day", so the names read P0n-dayb / P0n-dayc.
