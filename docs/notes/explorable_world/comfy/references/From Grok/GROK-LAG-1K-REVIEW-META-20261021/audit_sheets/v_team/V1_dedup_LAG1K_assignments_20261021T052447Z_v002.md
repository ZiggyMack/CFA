This adds one rule from Ziggy (2026-10-21 05:25Z).
- If the shot is the same but the expression or mood differs (for example serene vs laughing, or a serious line vs a joke line), tag it VARIANT. That counts as different enough.
- If the expression variant also shows identity drift (it reads as a different person), tag it VARIANT and add IDENTITY-DRIFT in the note, naming the feature that drifted. We keep the idea, but flag it as needing an on-model redo before it's used. Don't tag it DUPLICATE.
- In ZIGGY-PICK sheets, list mood variants side by side so Ziggy can see whether the identity holds across expressions.
