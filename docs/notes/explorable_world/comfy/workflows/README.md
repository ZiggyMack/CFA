## Quick controls from episode 3

**Copy a complete output branch.** In the flat SDXL recipe, select KSampler, VAE Decode and Save Image, copy with `Ctrl+C`, then paste with `Ctrl+Shift+V`. This retains incoming connections from unselected upstream nodes; a lone duplicated sampler does not automatically create another saved image. Check the pasted denoise link, fixed seed, prompts and unique filename prefix. If denoise still links to the original shared scalar, add a separate scalar or convert that input back to a widget before varying it. Official [shortcuts](https://github.com/Comfy-Org/ComfyUI#shortcuts) document the paste behavior; customized browser keybindings may differ.

**Change one thing at a time.** Keep the same input images, prompt and fixed seed while comparing a LoRA, style or denoise value. Shared scalar nodes intentionally update every connected branch. A fixed seed is part of the recipe, not a portable identity lock or a guarantee of identical pixels across model/runtime changes. Cached outputs can also reappear without new sampling. Keep the actual executed settings with a result.

The UI toggles have not been executed as new tests. If another output or preview is later connected to a sampler, mute that terminal too. Cloud runtime may still apply to input-only execution.

**Keep the canvas readable.** Leave large Save/Preview nodes outside the processing subgraphs, as our reference editor and comparison already do. A colored group arranges nodes; a [subgraph](https://docs.comfy.org/interface/features/subgraph) encapsulates them. Collapsing or hiding controls changes presentation, not execution. Bypass reconnects compatible inputs/outputs and is useful for an optional adapter; it is not a universal off switch for required conditioning or entire generation branches.

**Batch deliberately.** Latent batch size, repeated queued jobs and multiple connected output branches are different ways of requesting work. More branches do not establish parallel GPU execution. Keep a single deliberate run for an initial check; enable batch/automatic queueing only with a chosen number of outputs and an understood Cloud budget. The tutorial's local GPU timing is not a Cloud performance or cost estimate.
