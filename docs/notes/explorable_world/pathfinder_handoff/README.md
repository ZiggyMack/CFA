   [LESSONS.md](../comfy/LESSONS.md). Cite an immutable revision or retain a

   understand an experiment. Avoid copying whole evolving guides by default.

   environment, relevant primary documentation and recorded results. A newer
   guide or a historical successful run alone does not establish current
   compatibility. Keep researched, available, executed and accepted distinct.

   ledger: the problem, corrected method, source/result evidence and remaining
   limits. Ziggy's October 4 instruction authorizes these documentation updates
   on each intake. Check current files before editing, preserve another Nova's
   ongoing work, and return teaching integration results through CFA_FEEDBACK.
