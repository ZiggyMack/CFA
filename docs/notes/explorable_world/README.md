**How Comfy feeds the game.** Keep recipes and asset records in comfy/, with generated originals in cloud storage and only necessary local copies in its ignored outputs/ folder on D:. Review and clean up a selected asset, then copy or export the accepted derivative into the game's assets/ directory. Assemble it in a scene and add collision, interaction, sound, and state changes. The game should load its own accepted assets; it should not depend on temporary download links or the ignored experimental output folder. An image can also serve as reference for simple authored geometry.
