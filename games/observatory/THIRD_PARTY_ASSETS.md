# Third-party materials

The game uses nine 1K JPEG maps (diffuse, OpenGL normal, roughness) from these
Poly Haven assets:

| Asset | Source |
| --- | --- |
| Stone floor | https://polyhaven.com/a/stone_floor |
| Stone wall 03 | https://polyhaven.com/a/stone_wall_03 |
| Wood planks | https://polyhaven.com/a/wood_planks |

Poly Haven releases these asset files under **CC0 1.0**. See its
[asset license](https://polyhaven.com/license) and the
[CC0 dedication](https://creativecommons.org/publicdomain/zero/1.0/).
The nine downloaded files total 6,861,358 bytes. Exact URLs, byte counts and
SHA-256 hashes are in [assets/materials/provenance.json](assets/materials/provenance.json).

The game geometry, water shader, dialogue, and synthetic ambience are authored
project work. The first Comfy pump concept informed the authored pump; this
visual pass did not generate or import an AI mesh. The Godot runtime's MIT
license is distributed separately in GODOT_LICENSE.txt.
