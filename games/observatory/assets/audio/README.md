# Observatory sound studies

These two short mono WAV loops were synthesized for this prototype using deterministic noise and sine tones. No external recording or model was used. `lakeside.wav` supplies a quiet wind-like bed; `water.wav` is spatialized near the fountain when the supply is restored. These are temporary sound-design materials, independently replaceable from story behavior.

The game provides a sound toggle in the pause menu and the M shortcut. Both loops play at restrained levels.
